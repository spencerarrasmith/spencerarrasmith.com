## [Telugu](content/lang/telugu/index.html) 
With some (a lot) of help from Claude, I built a set of apps to learn Telugu my way. These apps are heavily inspired by the book [Learn Telugu Through English in 30 Days](https://www.amazon.com/dp/8128811886?lv=shuf&channelId=500&plpRedirect=mhFallback), which provides an excellent structure but is about as interesting as reading nutrition labels in order to learn how to cook.

These apps initially began with the Phoneme game, where the user is shown a Telugu character and has to select the corresponding IPA phoneme. I created this for myself as a study tool before discovering the book, and used it sparingly. After being gifted a copy of this book, I started colluding with Claude heavily in order to build out more pages for learning Telugu. Since Javascript/HTML/CSS is not the primary focus, this is all effectively vibe code for now. As I use each tool for learning, I have been expanding the feature set so that it matches my needs and makes the learning process at least a little game-ified.

Future work would be to package this as a proper standalone app, since it works well on desktop and mobile.
